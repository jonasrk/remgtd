# Step Guide

The Step Guide text lives in [`src/remgtd/content/step_guide.md`](../src/remgtd/content/step_guide.md), so the View and this documentation can't drift apart. The View renders it as five cards (Capture, Clarify, Organize, Reflect, Engage), each with a live status from your data.

To change the guidance, edit that file and keep its structure:
- `## <n>. <Step>` headings
- `**Purpose:**`, `**Start point:**`, `**End point:**` and `**Live status:**` lines
- `**Key questions**` and `**Advice**` followed by bullet lists
